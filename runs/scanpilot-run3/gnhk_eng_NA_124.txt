HMM Training
① Initialization ( IS₁, IS₂, ... , ISN )
A. Samples (5 ~ 12) -> divide into N initial states (evenly)
B. Calculate Avg length of each state
( l₀₁, l₀₂, ... l₀N )
c. Calculate initial transition prob
P₀i = 1 / l₀i ( P₀₁, P₀₂, ... P₀N )
d. Calculate μ, σ² for each state
( μ₀₁, ... μ₀N / σ₀₁, ... σ₀N )
② Loops (1, 2, ... t)
A. for each point x (near boundary), compare (x - μK) / σK vs (x - μK+1) / σK+1
decide if to move x to another state
B. Calculate Avg length of each state ( lt₁, lt₂, ... ltN )
c. Calculate transition prob ( pt₁, pt₂, ... ptN )
D. Calculate μ, σ for each state ( μt₁, ... μtN / σt₁, ... σtN )
if boundaries don't change => converge!
* Note that each state must have ≥ 1 point!
